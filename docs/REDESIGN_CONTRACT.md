## Page chrome / Back button (A1 owns the primitives, A5 applies sweeps)
`PageHeader({title, description?, crumbs?, backHref?, actions?, eyebrow?})` keeps its current props (backwards compatible) and renders: BackButton, breadcrumb (≥sm), eyebrow, h1 (`.t-h1`), description, actions. `BackButton({fallbackHref, label?})` is a client component: goes `router.back()` ONLY when the previous history entry is a page of this app (tracked by a small in-app navigation tracker in the shell using `sessionStorage`; never rely on `document.referrer`/`history.length` alone) AND it isn't the same page or a child of it (no loops); otherwise `router.push(fallbackHref)` where fallback = explicit `backHref` or the last crumb with an href or `/dashboard`. Dashboard itself has no back button. Visible on every inner page in the same position (top-left of content, 44px min target, text "Back" + destination name from sm up).
